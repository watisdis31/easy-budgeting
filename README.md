# 💸 EZ-Budgeting  
**Because coping is expensive. Data is cheaper.**

EZ-Budgeting is a simple personal finance tracker that shows you where your money *actually* goes — not where you think it went.

Track income, expenses, daily spending, and monthly comparisons so your wallet can stop gaslighting you.

---

## ✨ Features
- 📅 Calendar-based daily tracking (device-based timezone)
- 💰 Income & expense logging with categories
- 📊 Daily & monthly summaries
- 🥧 Pie chart (day / month)
- 📈 Month-to-month comparison
- 🎮 Retro Pokémon-style UI
- 🔐 Google Sign-In (Firebase)

## 🔐 Security (Important but Chill)

This app uses **Firebase Authentication** and **Firestore Security Rules**.

A few things to be very clear about:

- ✅ I **cannot** read or write other users’ data  
- ✅ You **cannot** read or write other users’ data  
- ❌ This app does **NOT** connect to your bank account  
- ❌ No credit cards, no spying, no funny business  

### About Firebase API Keys

Yes, Firebase API keys exist in the frontend.  
That’s **normal and safe**.

Security is enforced through:
- Firebase Authentication
- Firestore access rules
- Domain restrictions

So even if someone copies the key:
> They still get **nothing** 🎉
